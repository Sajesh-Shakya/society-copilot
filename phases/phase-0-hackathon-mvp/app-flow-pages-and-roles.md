# **app-flow-pages-and-roles.md**

## Site map

* Home (task input)
* Workflow page
* Draft review page
* Approval inbox
* History / audit

---

## Page purposes

* Home → start any task
* Workflow → guided input
* Draft → review output
* Approval → approve/reject
* History → track actions

---

## User roles

### Treasurer

* approves finance
* runs payment chaser

### President

* approves key actions
* handles bookings

### Secretary

* manages comms
* drafts responses

---

## Primary user journeys

### 1. Payment chase

1. Click “Chase payments”
2. Review generated list + messages
3. Approve → send

---

### 2. Plan trip

1. Type “Plan trip”
2. Answer 3–5 questions
3. Review outputs → approve

---

### 3. Room booking

1. Click “Book room”
2. Select slots
3. Approve draft
